# 源与独立运行

## 现在是什么结构

影视仓 App **不再依赖家里那台电脑**：

- 首页：手机直接向源站要数据，边拉边显示；
- 分类：按 `docs/sub.json` 里每个源的真实子分类表（`map`）抓对应分类，再在手机上去重；
- 搜索：21 个源并发，单源最多 3.6 秒，先回来的先显示；
- 详情：同一部片的多源同时展开，合并线路；每条线路先探测第一集，能连上的排在前面；
- 播放：跳过体检判坏的线路，8 秒还 0 秒缓冲就自动换下一条。

PC 的 `8899` 服务现在只是**增强项**：在同一个 Wi-Fi 下会自动探测，能用就用精选片单和小鸡 4K；探测失败最多等 1.5 秒，然后完全走本地源。朋友手机没有这台 PC，也能正常用。

## 源清单

唯一入口：`docs/sub.json`

```json
{
  "key": "s0",
  "name": "光速资源",
  "api": "http://.../api.php/provide/vod",
  "cats": { "movie": "1", "series": "2" },
  "map": { "1": "movie", "2": "series", "6": "movie" },
  "ms": 3569
}
```

- `cats`：一级分类的默认子分类 id；
- `map`：这个源所有真实子分类 → 一级分类的映射，分类页靠它抓数据；
- `ms`：最近一次响应耗时，只用于排序，不参与内容判断。

`SEED` 里内置同一套 21 个源。远程订阅只有旧版 12 源时，App 会按 API 合并，保留内置的 21 源和 `map`，不会被缩回去。

## 私密内容

默认 `showPrivate=false`：首页、分类、搜索、详情都不会出现“伦理/情色/成人/写真”等条目，分类筛选也不会出现“伦理片”这种入口。只有“我的 → 设置 → 显示「私密」分类”打开后才放行。

## 发版前必须跑

```bash
# 1. 源站独立体检（不经过 PC）
node tools/qa/standalone_sources.mjs

# 2. 手机主路径（需要 adb 连着手机）
python tools/qa/phone_smoke.py
```

`standalone_sources.mjs` 逐源测列表、搜索、详情和第一条播放地址；`phone_smoke.py` 以普通用户视角走首页 → 分类 → 搜索，检查源数量、筛选项、私密内容泄露和搜索出结果时间。

## 当前体检结论

2026-11-26 的本机网络下：21 个源里能出搜索结果的约 12 个，能完整走通列表/详情/播放的约 7 个；因此 App 不追求“所有源都成功”，而是**限制单源超时、先显示已成功的、死链自动跳过**。源站恢复或换域名时，只改 `docs/sub.json`，不用重新发 APK。
