## 构建 / 安装 / 发布

```bash
cd /c/AI/demo/yingyin-app
C:/Tools/gradle-8.7/bin/gradle.bat -p android assembleRelease --console=plain
C:/Tools/android-sdk/platform-tools/adb.exe -s 83e3caf8 install -r android/app/build/outputs/apk/release/app-release.apk
```

发布：

```bash
cp android/app/build/outputs/apk/release/app-release.apk yingyin-<ver>.apk
gh release create v<ver> yingyin-<ver>.apk --title "<ver> · <标题>" --notes-file <notes>
```

GitHub push 在本机用 `git -c http.sslBackend=openssl push origin main`；不要用 schannel，会 SSL 握手失败。`gh` 已登录 `lxl-65`（token 不写进任何文件）。

## 坑

- 这台 Git Bash 里 `taskkill //F` 会被转义，杀 8899 占用要用 `powershell -NoProfile -Command "Stop-Process -Id <pid> -Force"`。
- `NewScreens.kt` 是 CRLF；用脚本整段替换时按 `newline=''` 处理，patch 容易被行尾坑。
- 没有 `/api/facets` 独立接口；facets 随 `/api/list` 响应返回。
- 网页端 `public/app.js:24` 仍有 22s abort，未改；不影响 App。
- 不要用混元模型；代码/难 bug 用 `code/deep`，批量整理用 `cheap`。
- 任何 token / 密码 / 签名口令都不写进仓库、交接文档或聊天。
